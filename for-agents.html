For agents

This site has a machine interface.

Most pages here are written for a browser. This page is the machine-readable front door: the same content, in the formats agents already read. It is static files only — there is no API endpoint behind it yet, and nothing here claims otherwise.

Policy

What crawlers and models may do with it.

  • Public content on this site may be read, summarized, and cited. Nothing here is behind a credential, so do not probe for a login.

What is deliberately missing

Knowing which standards do not apply is part of implementing them.

  • There is no MCP endpoint, no JSON-RPC tool list, no linkset, and no agent-identity document — because this site serves none of those yet. A tool list with no tool behind it is worse than none.
  • There are no per-page Markdown twins. The generator does not produce them yet.
  • There are no user accounts and no credentials are issued. There is no commerce surface either — nothing here is for sale to a machine.

Planned, not live: a real read-only endpoint (for example a projects list) will be listed here only once it is actually served.
